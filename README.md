# Streak

Приложение для macOS, которое помогает не бросать учёбу. Отмечаешь часы за день, ставишь задачи с напоминаниями — и видишь, как растёт серия.

## Что есть

Календарь на месяц. День закрашивается зелёным, если там есть запись. Чем больше часов — тем темнее. Под числом пишется количество часов. Текущий день обведён акцентом.

Задачи. Добавляешь задачу на любой день, ставишь время и получаешь уведомление. На календаре под числом появляется точка: красная — есть незакрытые задачи, зелёная — все сделаны.

Статистика справа: streak (сколько дней подряд занимаешься), всего часов за месяц, среднее в день, лучший день, сколько задач выполнено из общего числа.

График внизу — столбики часов по дням месяца. Дни без записи серые.

Отдельный блок справа снизу — задачи на ближайшие 7 дней.

## Запуск

Xcode 26+, macOS 26.5+.

1. Клонируй репозиторий
2. Открой `Streak.xcodeproj`
3. `Cmd+R`
4. При первом запуске спросит разрешение на уведомления — разреши, если хочешь получать напоминания

## Где хранятся данные

`~/Library/Application Support/Streak/data.json`

Никаких серверов, аккаунтов, синхронизаций. Всё локально.

## Частые вопросы

**Почему серия не считается, хотя я занимался?**
Streak рвётся, если пропустил день. Если сегодня ещё ничего не отмечал, но вчера отмечал — серия продолжается. Пропустил вчера — счёт с нуля.

**Уведомление не приходит.**
Проверь в **Системные настройки → Уведомления → Streak**, разрешены ли уведомления. Если приложение не запущено, уведомление всё равно должно сработать — оно ставится системой.

**Как удалить запись за день?**
Открой день → «Удалить запись». Задачи удаляются отдельно, кнопкой с крестиком рядом с каждой.

**Где лежат данные?**
В JSON-файле по пути выше. Можно бэкапить, копировать между Mac'ами.
